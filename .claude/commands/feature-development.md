# Feature Development

When implementing a feature in Bill Analyser:

1. Read [CLAUDE.md](CLAUDE.md) and [.github/copilot-instructions.md](.github/copilot-instructions.md).
2. Identify whether the change affects backend, frontend, or both.
3. Preserve async bridge, REST contracts, and money-unit conversions.
4. Add or update targeted tests before closing the task.
5. Summarize risks, verification, and any remaining follow-up work.
