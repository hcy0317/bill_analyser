# Bill Analyser 项目总览

`BILL_ANALYSER_API_PORT=5001`），再通过 `BILL_ANALYSER_PYTHON_UPSTREAM=http://127.0.0.1:5001` 反向代理尚未迁移的端点；`proxy_only` 模式仍可代理未接管的 `/api/*`，但 `import_db_runtime` 模式只允许 manifest 中标记为 `PythonProxied` 的端点进入 Python，未知 `/api/...` 不再静默透传。Rust runtime metadata 现在声明 `api_takeover=true`，`import_db_runtime` 模式的 `business_migration` 标注为 `import-db-runtime+bills-crud-runtime+budgets-crud-execution-forecast-history-import-runtime+statistics-read-runtime-partial+auth-login-register-token-session-personal-refresh-logout-profile-cloud-external-auth-system-runtime`。默认 `import_db_runtime` 模式下，Rust 直接接管 import v2 JSON parse/parse_generic/dedup/confirm、前端 FormData CSV 上传解析、未匹配文件 temp preview 与列映射 parse_generic、session 读取/清理、preview 分页读取、preview update/reclassify 显式 DB 更新、preview-item transfer/recurring 决策、learning 会话预览旁路与 promotion、LLM accept/reject/memory 事件与 OCR config app_settings 读写，并接管核心账单/交易 CRUD 路由、预算 CRUD/export/execution/forecast/history/snapshot/import 路由、DB-backed 统计读取路由（`GET /api/statistics/category-statistics`、`GET /api/statistics/category-statistics/trends`、`GET /api/statistics/asset-trends`、`GET /api/statistics/category-pie`、`GET list/unlink、profile 验证邮件重发和 system version 路由（`POST /api/auth/login`、`POST /api/auth/register`、`GET /api/tokens`、`DELETE /api/tokens`、`DELETE /api/tokens/{token_id}`、`POST /api/tokens/api`、`POST
