# Bill Analyser 项目总览

多来源账单导入 + 智能去重 + 自动分类 + 多维统计分析全栈系统。Rust 已成为主 HTTP 服务入口：`bill_http_server` 默认监听 `BILL_ANALYSER_HTTP_BIND=127.0.0.1:5000`，`start_backend.ps1` 先启动 Python/Flask sidecar（默认 `BILL_ANALYSER_API_PORT=5001`），再通过 `BILL_ANALYSER_PYTHON_UPSTREAM=http://127.0.0.1:5001` 反向代理尚未迁移的端点；`proxy_only` 模式仍可代理未接管的 `/api/*`，但 `import_db_runtime` 模式只允许 manifest 中标记为 `PythonProxied` 的端点进入 Python，未知 `/api/...` 不再静默透传。Rust runtime metadata 现在声明 `api_takeover=true`，`import_db_runtime` 模式的 `business_migration` 标注为 `import-db-runtime+bills-crud-runtime+budgets-crud-execution-forecast-history-import-runtime+statistics-read-runtime-partial`。默认 `import_db_runtime` 模式下，Rust 直接接管 import v2 JSON parse/parse_generic/dedup/confirm、前端 FormData CSV 上传解析、未匹配文件 temp preview 与列映射 parse_generic、session 读取/清理、preview 分页读取、preview update/reclassify 显式 DB 更新、preview-item transfer/recurring 决策、learning 会话预览旁路与 promotion、LLM accept/reject/memory 事件与 OCR config app_settings 读写，并接管核心账单/交易 CRUD 路由、预算 CRUD/export/execution/forecast/history/snapshot/import 路由，以及 DB-backed 统计读取路由（`GET /api/statistics/category-statistics`、`GET /api/statistics/category-statistics/trends`、`GET /api/statistics/asset-trends`、`GET /api/statistics/category-pie`、`GET /api/statistics/top-merchants`、`GET /api/statistics/amounts`）；同一模式可用前端 Bearer access token 校验 HS256/HS384/HS512 HMAC JWT、`sessions.token_hash`、用户启用状态与 session 过期时间。账户/标签/分类/模板、设置包 taxonomy helper 与分类规则表达式编译等路径已逐步通过内部 Rust crates/bridge 接管，导入/学习/matching/recurring/budgets/statistics、AI OCR/LLM provider/config 与 backup/ops 安全合同等路径也在 Rust crate 中固定合同层；`bill-analyser-db` 已提供 SQLite runtime path guard、WAL/FK 连接配置、foundational schema 初始化、core legacy user-scope/unique 迁移、schema dry-run copy validation、导入 session、preview、parser template staging、StandardBill-to-parser-template adapter、parser-template-to-preview staging adapter、selected preview confirm-to-bills、preview update/reclassify、preview-item transfer/recurring/learning decision、learning promotion、preview LLM recommendation/memory event、OCR config app_settings 与 annotation sample，以及账单 CRUD、预算 CRUD/export/execution/forecast/history/snapshot/import 和统计读取聚合的 Rust SQLite 原语及回滚/user-scope/父子预算上卷合同测试。parser-specific Excel/XLSX、完整 Python parser parity、SQLCipher/encryption schema、账单导出、交易图片、reconciliation statements、自动 recurring 候选/匹配生成、统计 Analyzer overview/trends/comparison/category/trend、真实汇率 provider 与 custom exchange-rate 写入、模型生成、真实 LLM provider 推荐（`POST /api/llm/preview-recommend`、`/analyze-transactions`、`/rule-synthesis`）、全局 Learning Center suggestions/rules 循环（`/api/learning/suggestions*`、`/api/learning/rules*`）、OCR 图片识别以及自动分类式 reclassify 编排仍由 Python sidecar 保留；Rust 路由、DB 写入语义、前端导入流程、全量 coverage、无残留引用五项证据未同时通过前，Python import 删除仍阻塞，Python bills/budgets/statistics 删除也因残留引用继续阻塞。前端 Vue 3/TypeScript/Vite，数据库 SQLite WAL 模式。
