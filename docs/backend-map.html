Bill Analyser Backend Map

The backend is a Rust-only Axum service. bill_http_server owns every runtime HTTP route under /api/...; PostgreSQL is the only business database and Weaviate is required for derived vector recall.

Crates

  • src/backend/http: routers, auth context, DTO parsing, response envelopes, uploads, and route facades.
  • src/backend/core: domain contracts for money, dates, import, matching, budgets, statistics, OCR/LLM, auth, backup, and governance.
  • src/backend/db: SQLx PostgreSQL pool, schema scripts, repositories, import staging, backup metadata, and vector outbox.
  • src/backend/parsers: dedicated parsers and standard bill normalization.

Runtime Invariants

  • BILL_ANALYSER_DATABASE_BACKEND accepts only postgres / postgresql.
  • BILL_ANALYSER_POSTGRES_URL must be configured and reachable.
  • Weaviate must pass the ready probe for /api/health to be ok.
  • Route handlers must not open alternate database runtimes.

Import Pipeline

Upload routes parse files, create import sessions, stage normalized rows, run dedup and transfer materialization, apply category/account rules, request Weaviate recall when deterministic learning misses, render preview pages, persist manual edits, and confirm selected rows in PostgreSQL transactions.
