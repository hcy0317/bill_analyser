Bill Analyser Rust 后端导航图

Canonical source: docs/backend-map.md

本页是静态阅读入口，核心事实以 Markdown 源文件为准。当前运行态由 Rust Axum REST /api/...、PostgreSQL repository 层和必需的 Weaviate derived index 共同承接。

后端分层

HTTPsrc/backend/http

Axum 路由、认证上下文、请求 DTO、response envelope。

Coresrc/backend/core

业务合同、金额/时间/分类、导入、匹配、预算、统计、LLM/OCR。

DBsrc/backend/db

PostgreSQL SQLx pool、schema/migrations、事务、user-scope repository、vector outbox。

Parserssrc/backend/parsers

provider 检测、RawBill、StandardBill、fixture/golden 合同。

开发路径

新增 API

先找 route facade，再确认 auth、DTO、envelope、user-scope。

新增 parser

说明 provider identity、RawBill/StandardBill 和 fixture 期望。

改导入预览

区分 parser、dedup/materialization、category/type、learning projection、account rules、selection、transfer、confirm 边界。

改 repository

先确认事务和 user-scope，不把 schema 改动混进普通查询。
